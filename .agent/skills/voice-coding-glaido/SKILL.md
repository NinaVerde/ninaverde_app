# Voice Coding Protocol (Glaido/Voice Control)

## Setup
To enable true "Antigravity" voice coding (as seen in Video 6):
1.  **Tooling**: Ensure you have a voice-to-text tool enabled (e.g., Glaido, Windows Dictation, or Mac Voice Control).
2.  **mode**: Use "Conversational Coding" mode.

## Voice Prompting Best Practices
When the user dictates code or logic:
-   **Listen for Intent**: Voice transcripts often contain typos/homophones (e.g., "write" vs "right", "function" vs "fiction"). Infer the *coding intent* over literal text.
-   **Confirm Ambiguity**: If a variable name sounds ambiguous (e.g., "camel case variable ID"), confirm the spelling before refactoring.

## "Vibe Coding" via Voice
-   If the user says "Make it pop" or "Give it some juice", interpret this as:
    -   Add animations (`flutter_animate`).
    -   Increase contrast or shadow depth.
    -   Add haptic feedback.
