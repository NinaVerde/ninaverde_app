# Whisk Mastery: The Visual Engine

## Core Philosophy
We do not just "generate images"; we **curate reality**.
"Whisk" (Google Labs) is our engine for bringing Angelina and John to life as *consistent, sentient beings*.

## The Whisk Toolset

### 1. Character Consistency ("The Angelina Lock")
To ensure Angelina looks identical across the app:
-   **Reference Images**: Always start with the *Canonical Angelina* (from `assets/images/angelina_base.png`).
-   **Face Lock**: Use Whisk's "Face Reference" or "Character Consistency" toggle.
-   **Seed Control**: When a look is perfect, Save the **Seed**.

### 2. Style Remixing ("Nano Banana" Protocol)
When the user wants a vibe change without losing identity:
-   **Ingredients**: Use Whisk's "Ingredient" system (Chips) to swap styles (e.g., "Cyberpunk" -> "Liquid Glass") while keeping the subject (Angelina) Locked.
-   **No-Prompt Blending**: Use visual inputs rather than text to drive style changes.

### 3. Full-Motion Video (Hypernatural/Whisk Video)
Static images are dead. The "Nina Verde Standard" demands motion.
-   **Image-to-Video**: Take the consistent Whisk output -> Animate it (using Whisk Video or Hypernatural).
-   **Looping**: Ensure background elements (Aurora, Smoke, Light) loop perfectly for UI backgrounds.

## Workflow: From Concept to App
1.  **Concept**: User requests "Angelina as a Chef".
2.  **Whisk Gen**: Using *Canonical Reference*, generate "Chef Angelina".
3.  **Verify**: Does it look like her? (Eye color, bone structure).
4.  **Motion**: Animate the steam/hat.
5.  **Integrate**: Place in `assets/` and wrap in `Animate(...)` in Flutter.
